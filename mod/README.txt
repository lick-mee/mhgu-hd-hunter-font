HD Hunter Font - sharp in-game text for Monster Hunter Generations Ultimate

Install
  1. Put this folder (zz-hd-hunter-font) in the recomp's mods folder.
  2. Double-click install.bat.
  3. Start the game.

Using the HD texture mod? Run install.bat again whenever you update it.
Uninstall: delete this folder.
